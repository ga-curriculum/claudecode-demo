01
Claude vs Claude Code
Claude (claude.ai)
Thinks and designs with you
Reads your course documents
Builds the CLAUDE.md blueprint
Iterates in conversation
Claude Code (terminal)
Runs on your machine
Creates real files + folders
Pushes to GitHub directly
Follows CLAUDE.md exactly

The connection: Claude designs the CLAUDE.md → Claude Code builds the course from it. You need both.

02
Install Claude Code
Requires Node.js 18+ — install via nodejs.org or Homebrew
Install: npm install -g @anthropic-ai/claude-code
Set API key: export ANTHROPIC_API_KEY=sk-ant-...
Launch in any folder: claude
GitHub push: add a Personal Access Token with repo scope

04
Repository Architecture
One GitHub repo per module
[N]-[module-slug]/
├── README.md ← badges, Mermaid, PNG, AI section
├── instructor-guide.md
├── assets/ ← matplotlib dark theme PNG
└── Lab-[lab-name]/
    ├── README.md ← lab brief + tasks
    ├── data/
    │  ├── schema_and_seed.sql
    │  └── lab_starter.sql
    ├── outputs/
    │  └── my_answers.md
    └── solutions/
        └── lab_solution.sql
05
Build Locally → Deploy to GitHub
Create a folder for the course on your Mac — place CLAUDE.md inside
Open Claude Code in that folder: cd my-course && claude
Claude Code reads CLAUDE.md automatically — no extra setup
Prompt: "Build all modules following CLAUDE.md" — files appear locally
GitHub deployment (with token)
Add GitHub token to Claude Code — repos push automatically
Prompt: "Create repo for Module X and push" — done in seconds
